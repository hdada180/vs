A simple Python tool to check password strength.

tool.py — Password Strength Checker

Prompts the user for a password and evaluates its strength based on:

 • Length (minimum 8 characters)
 • Presence of uppercase and lowercase letters
 • Presence of numbers
 • Presence of special characters (@#$%^&*+=)

Usage:
python tool.py
Requirements: Python 3.x only, no external libraries.
