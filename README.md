Python Password Strength Checker
A robust command-line utility designed to evaluate password security and complexity in real-time.
Features
Analyzes character length, uppercase, lowercase, numbers, and special symbols.
Provides an instant security rating and feedback.
Installation & Execution
Clone the repository or download the ZIP archive from GitHub.
Open your terminal or command prompt inside the project folder.
Run the script using Python:

Bash
python tool.py
